# Example: CLI Tool

## Brief
Build a CLI tool that converts JSON to CSV with streaming support.

## Archetype
`cli-tool`

## Tier
T0

## Waves
1. **Core** — streaming parser, CSV writer, CLI interface
2. **Polish** — progress bar, error handling, man page
3. **Ship** — pip installable, GitHub release, homebrew formula

## Outcome
- `pip install json2csv-stream`
- 10K+ downloads in first month
- FM-12 (stale docs) prevented by auto-generated README from `--help`
