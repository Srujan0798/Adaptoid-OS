# Example: Research ML Project

## Brief
Reproduce and extend a paper on fair classification with demographic parity constraints.

## Archetype
`research-ml`

## Tier
T2

## Waves
1. Reproduction — baseline model, dataset, metrics
2. Extension — new fairness constraint, ablation study
3. Evaluation — statistical tests, comparison tables
4. Publication — LaTeX, figures, reproducibility package

## Outcome
- Paper accepted at FAccT 2026
- Full reproducibility package (Docker + data + code)
- FM-10 (flaky tests) caught by check_tests.sh — unseeded RNG fixed
