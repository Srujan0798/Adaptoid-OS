# Domain Workflow: IoT / Robotics

## Archetype
`startup-mvp` / `internal-tool`

## Phases
1. **Sense** — sensor selection, data pipeline, edge compute
2. **Think** — model training, decision logic, safety constraints
3. **Act** — actuator control, feedback loops, fail-safes
4. **Monitor** — telemetry, OTA updates, predictive maintenance
5. **Scale** — fleet management, security, compliance

## Agents
- **Embedded Engineer** — firmware + sensors
- **ML Engineer** — edge models + optimization
- **Safety Engineer** — fail-safes + compliance
- **DevOps** — OTA + fleet ops

## Verification
- Hardware-in-the-loop tests pass
- Safety constraints verified under all failure modes
- OTA rollback tested
- Regulatory compliance (FCC, CE, UL)

## Timebox
8 weeks (T3)
