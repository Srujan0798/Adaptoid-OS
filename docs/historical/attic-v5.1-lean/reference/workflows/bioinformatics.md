# Domain Workflow: Bioinformatics

## Archetype
`research-ml` / `data-pipeline`

## Phases
1. **Data** — acquire sequences, QC, alignment
2. **Pipeline** — variant calling, annotation, filtering
3. **Analysis** — statistical tests, pathway enrichment
4. **Visualization** — plots, dashboards, reports
5. **Publication** — methods, figures, supplementary data

## Agents
- **Bioinformatician** — pipeline + analysis
- **Statistician** — study design + tests
- **Visualization Engineer** — plots + dashboards

## Verification
- Reproducible pipeline (Snakemake/Nextflow)
- Test data with known ground truth
- Peer-review ready figures

## Timebox
8 weeks (T3)
