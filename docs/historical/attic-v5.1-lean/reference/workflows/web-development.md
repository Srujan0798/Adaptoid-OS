# Domain Workflow: Web Development

## Archetype
`saas-product` / `startup-mvp`

## Phases
1. **Design** — wireframes, component tree, API contract
2. **Backend** — database schema, API endpoints, auth
3. **Frontend** — components, state management, routing
4. **Integration** — connect frontend to backend, error handling
5. **Deploy** — CI/CD, staging, production

## Agents
- **Designer** — wireframes + component spec
- **Backend Engineer** — API + database
- **Frontend Engineer** — UI + state
- **DevOps** — deploy + monitor

## Verification
- API tests pass
- E2E tests pass
- Lighthouse score > 90
- Deploy succeeds to staging

## Timebox
4 weeks (T2)
