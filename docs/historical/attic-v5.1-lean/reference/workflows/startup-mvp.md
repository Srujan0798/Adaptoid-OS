# Domain Workflow: Startup MVP

## Archetype
`startup-mvp`

## Phases
1. **Validate** — market research, competitor analysis, problem-solution fit
2. **Scope** — T1 feature set, OUT list, falsification criteria
3. **Prototype** — landing page + core loop, no auth, no payments
4. **Demo** — pitch deck, metrics dashboard, user interview script
5. **Pitch** — YC-style 3-minute demo + Q&A prep

## Agents
- **Market Researcher** — validates demand
- **Product Engineer** — builds prototype
- **Pitch Designer** — creates demo + deck

## Verification
- 5 user interviews completed
- Landing page converts >10% demo signups
- Core loop works end-to-end

## Timebox
2 weeks (T1)
