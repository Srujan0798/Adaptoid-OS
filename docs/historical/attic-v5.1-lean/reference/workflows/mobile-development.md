# Domain Workflow: Mobile Development

## Archetype
`startup-mvp` / `saas-product`

## Phases
1. **Design** — user flows, screen map, design system
2. **Core** — navigation, state, API client
3. **Features** — screens, forms, lists, maps, camera
4. **Polish** — animations, accessibility, dark mode
5. **Ship** — app store submission, beta, release

## Agents
- **Mobile Engineer** — core + features
- **UI Designer** — screens + animations
- **Release Manager** — store submission

## Verification
- Builds on iOS and Android
- E2E tests pass on real devices
- App store review guidelines met

## Timebox
6 weeks (T3)
