# Domain Workflow: Game Development

## Archetype
`startup-mvp` / `saas-product`

## Phases
1. **Concept** — core loop, genre, target platform
2. **Prototype** — mechanics, physics, one level
3. **Production** — assets, levels, UI, audio
4. **Polish** — balance, performance, bug fixes
5. **Ship** — store submission, marketing, updates

## Agents
- **Game Designer** — mechanics + balance
- **Gameplay Engineer** — physics + AI + systems
- **Artist** — 2D/3D assets + animations
- **Audio Engineer** — sound + music

## Verification
- Core loop fun factor validated (playtest N=5)
- Performance: 60fps target platform
- No game-breaking bugs in critical path
- Store guidelines met

## Timebox
8 weeks (T3)
