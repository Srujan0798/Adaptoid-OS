# Domain Workflow: DevOps / SRE

## Archetype
`internal-tool` / `infrastructure`

## Phases
1. **Assess** — current infra, monitoring gaps, SLOs
2. **Design** — architecture, IaC, CI/CD pipeline
3. **Implement** — Terraform/Ansible, GitHub Actions, observability
4. **Harden** — security scanning, backup, disaster recovery
5. **Operate** — runbooks, alerting, on-call rotation

## Agents
- **Platform Engineer** — IaC + pipelines
- **SRE** — monitoring + SLOs + incident response
- **Security Engineer** — hardening + compliance

## Verification
- Infrastructure tests pass (terraform validate, ansible-lint)
- Monitoring covers all critical paths
- Disaster recovery tested quarterly
- SLOs defined and measured

## Timebox
4 weeks (T2)
