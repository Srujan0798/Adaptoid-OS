# Domain Workflow: Blockchain / Web3

## Archetype
`startup-mvp` / `saas-product`

## Phases
1. **Design** — smart contract architecture, tokenomics, security model
2. **Develop** — Solidity/Rust contracts, tests, deployment scripts
3. **Audit** — static analysis, formal verification, external audit
4. **Deploy** — testnet → mainnet, multisig, timelock
5. **Monitor** — on-chain metrics, incident response, upgrades

## Agents
- **Smart Contract Engineer** — Solidity/Rust + tests
- **Security Auditor** — static analysis + manual review
- **Tokenomics Analyst** — incentives + game theory

## Verification
- 100% test coverage on contracts
- No critical/high findings from audit
- Formal verification for critical invariants
- Deployment verified on testnet

## Timebox
6 weeks (T3)
