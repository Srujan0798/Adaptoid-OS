## Channel checklist (in order)

### 1. PyPI release (owner action — needs your account)

```bash
python3 -m pip install build twine
python3 -m build            # uses pyproject.toml (adaptoid-os 5.4.0)
python3 -m twine upload dist/*
```

Then flip README to plain `uvx adaptoid-os …`.

### 2. Proof artifact — public demo repo

- `adaptoid --brief "real small product" --output demo && cd demo` → run one full wave with a real host → commit everything **including** `work/reports/` (the evidence trail is the demo).
- Name it `adaptoid-demo-<product>`; link from README.
- Every winner has one reproducible wow; this is ours.
