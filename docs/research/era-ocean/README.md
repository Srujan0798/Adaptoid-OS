# Era Ocean — continuous agentic-world research

> **Honesty contract:** This corpus is a **scrape + synthesis loop**, not a finished map.  
> We have **not** covered 1% of the agentic ecosystem. The ocean is larger than any single wave.  
> Goal: keep mining live sources and distill the **elite 10% concepts** that matter for Adaptoid Core.

## Why this exists

Adaptoid = **adaptive harness / mission OS**. Models and hosts churn.  
The only durable edge is **loop + harness + evidence** patterns that compound.

## Structure

```
era-ocean/
  README.md                 ← this file
  MANIFEST.md               ← wave log, coverage %, next targets
  elite/
    ELITE-10-PERCENT.md     ← distilled concepts for product (living)
  waves/
    wave-YYYYMMDD-HHMM.md   ← per-wave findings
  sources/
    INDEX.md                ← source registry by category
  raw/                      ← optional dump notes
  scripts/
    wave_runner.sh          ← kick a research wave (human/agent)
```

## Loop design (24h)

1. **Scrape** live surfaces (docs, GitHub, HN, Reddit, X, news, YC)  
2. **Extract** concepts (not vendor marketing)  
3. **Rank** by: compounds for harness / evidence / multi-host / failure prevention  
4. **Diff** against current Adaptoid Core  
5. **Propose** adopt / watch / refuse  
6. **Never** mark complete — update coverage estimate downward if ocean grows
