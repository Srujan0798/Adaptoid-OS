# Code of Conduct

## Our Standards
- **Evidence over ego.** Claims without evidence are bugs.
- **Honest status.** If it failed, say so. If you're unsure, say so.
- **Surgical changes.** Touch only what the task requires.
- **Never delete — archive.** History prevents re-trying failed paths.
- **Help others learn.** Document the "why" behind decisions.

## Unacceptable Behavior
- Silently absorbing scope creep (FM-08).
- Claiming "done" without running verification (FM-09).
- Deleting failed work instead of archiving it.
- Micromanaging agents or disabling guardrails.

## Enforcement
Maintainers will remove contributions that violate these standards. The kit validates itself; contributors should too.
