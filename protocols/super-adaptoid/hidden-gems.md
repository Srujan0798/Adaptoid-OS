# Hidden Gems Protocol

> Discover, evaluate, and integrate lesser-known tools and patterns.

## Purpose

Systematically scan the agentic-AI ecosystem for high-leverage but under-hyped tools, SDKs, and patterns, evaluate them against Adaptoid criteria, and add the winners to the ecosystem catalog.

## Core Rituals

1. **Scan** — monitor repositories, papers, and practitioner notes for emerging tools.
2. **Filter** — apply the "harness-first" lens: does it improve safety, speed, or verifiability?
3. **Verify** — reproduce the tool's core claim in a sandbox before cataloging.
4. **Catalog** — add to `reference/ecosystem/hidden-gems.md` with `last-verified:` frontmatter.

## Relationship to Kernel

This protocol extends `reference/ecosystem/` and applies `FM-12` (stale docs) by requiring freshness metadata.
