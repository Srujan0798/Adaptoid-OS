# Domain Workflow: Data Science

## Archetype
`data-pipeline` / `research-ml`

## Phases
1. **Explore** — EDA, data quality audit, baseline model
2. **Clean** — missing values, outliers, feature engineering
3. **Model** — train 3+ models, cross-validation, hyperparameter sweep
4. **Evaluate** — metrics, fairness, interpretability
5. **Deploy** — API endpoint, monitoring, drift detection

## Agents
- **Data Engineer** — ETL + cleaning
- **ML Engineer** — model training + tuning
- **ML Ops** — deployment + monitoring

## Verification
- Reproducible notebook / pipeline
- Test set held out, never leaked
- Model card + fairness report

## Timebox
4 weeks (T2)
