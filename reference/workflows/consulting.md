# Domain Workflow: Consulting

## Archetype
`internal-tool` / `saas-product`

## Phases
1. **Discovery** — client interviews, data audit, stakeholder map
2. **Diagnosis** — root cause analysis, gap assessment
3. **Recommendation** — solution options, ROI, implementation plan
4. **Deliver** — report, presentation, workshop
5. **Handoff** — knowledge transfer, change management

## Agents
- **Business Analyst** — discovery + diagnosis
- **Solution Architect** — recommendations
- **Engagement Manager** — client relationship + handoff

## Verification
- Client sign-off on each phase
- Measurable impact agreed upfront
- Knowledge transfer test (client can reproduce)

## Timebox
2–8 weeks (T1–T3)
