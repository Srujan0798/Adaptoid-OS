# Domain Workflow: Hackathon (48h)

## Archetype
`hackathon`

## Phases
1. **Hour 0–2:** Ideate + validate — pick the smallest impressive demo
2. **Hour 2–8:** Skeleton — one happy-path flow, fake the rest
3. **Hour 8–24:** Core loop — the one thing that wows judges
4. **Hour 24–40:** Polish — UI, animations, edge cases
5. **Hour 40–48:** Demo prep — script, backup plan, pitch

## Agents
- **Hacker** — builds the core
- **Designer** — makes it look finished
- **Pitcher** — crafts the story

## Verification
- Demo works 100% of the time on happy path
- Backup video ready
- Pitch under 3 minutes

## Timebox
48 hours (T0)
