# Domain Workflow: Education / Tutoring

## Archetype
`internal-tool` / `saas-product`

## Phases
1. **Assess** — student level, learning gaps, goals
2. **Curriculum** — personalized learning path, modules, assessments
3. **Deliver** — lessons, exercises, feedback loops
4. **Measure** — progress tracking, mastery metrics, adapt path
5. **Certify** — completion badges, portfolio, recommendations

## Agents
- **Assessment Engineer** — diagnostics + leveling
- **Curriculum Designer** — learning paths + content
- **Tutor** — delivery + feedback
- **Analyst** — progress + adaptation

## Verification
- Pre/post assessment shows improvement
- Student engagement metrics > 70%
- Content accuracy verified by subject expert

## Timebox
4 weeks (T2)
