# Domain Workflow: Content Creation

## Archetype
`internal-tool` / `startup-mvp`

## Phases
1. **Brief** — audience, tone, distribution channels
2. **Research** — sources, interviews, data
3. **Draft** — outline, first draft, self-edit
4. **Review** — fact-check, style check, SEO check
5. **Publish** — format for platform, schedule, promote

## Agents
- **Researcher** — sources + interviews
- **Writer** — draft + edit
- **Editor** — review + polish
- **Distributor** — platform formatting + promotion

## Verification
- Fact-check all claims
- Plagiarism scan clean
- SEO score > 80
- Engagement metrics tracked

## Timebox
1 week per piece (T1)
