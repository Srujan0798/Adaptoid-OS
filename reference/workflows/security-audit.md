# Domain Workflow: Security Audit

## Archetype
`internal-tool` / `saas-product`

## Phases
1. **Scope** — assets, threat model, compliance requirements
2. **Recon** — dependency scan, secrets scan, infra mapping
3. **Test** — static analysis, dynamic analysis, penetration testing
4. **Report** — risk scoring, remediation roadmap, PoCs
5. **Remediate** — fix high/critical, verify fixes, re-test

## Agents
- **Security Analyst** — threat model + scope
- **Penetration Tester** — attack surface + exploitation
- **Compliance Reviewer** — policy alignment

## Verification
- No critical vulnerabilities unpatched
- All secrets rotated
- Compliance checklist complete

## Timebox
2 weeks (T2)
